# Working rules for Claude

## Code changes need approval

DO NOT add, edit or remove code without my approval.

- Before changing any file (code, Terraform, workflows, config, docs), describe what you plan to change and why, then wait for me to approve it.
- Approval covers only the change I approved. Ask again for anything new or different.
- Reading files, searching, and running read-only commands (for example `terraform validate`, `terraform plan`, `kubectl get`) is fine without asking.
